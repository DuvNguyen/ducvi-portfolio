### E-commerce Platform for Used Sneakers (VietSneaker)

_Full Stack Developer_ | _[Month, Year] – [Month, Year]_

**Project Description:** Developed a comprehensive e-commerce platform specializing in used sneakers. The application provides a seamless shopping experience for customers and a robust management system for administrators, featuring AI-powered product recommendations and an interactive chatbot.

**Technologies Used:**

- **Backend:** Java, Spring Boot (Spring MVC, Spring Data JPA, Spring Security, Spring WebFlux), Hibernate.
- **Database & Caching:** MySQL, Redis, H2 (for testing).
- **Frontend:** React, Next.js, TypeScript, Tailwind CSS, Shadcn UI, SASS, Zustand/Context API (for state management).
- **Integration & Tools:** OAuth2, JWT, Cloudinary (Image Management), JobRunr (Background Jobs), OpenRouter/DeepSeek API (AI Integrations), Swagger/OpenAPI.

**Key Features & Responsibilities:**

- **Authentication & Authorization:** Implemented robust security using Spring Security, JWT, and OAuth2. Designed Role-Based Access Control (RBAC) with distinct roles such as System Admin, Product Admin, Inventory Manager, and Customer.
- **E-commerce Core:** Developed RESTful APIs for end-to-end e-commerce workflows, including product catalog browsing, dynamic search/filtering, shopping cart management, secure checkout, and order history tracking.
- **AI Integration:** Integrated an AI-driven product recommendation engine and an intelligent chatbot (via OpenRouter/DeepSeek APIs) to analyze user browsing history and enhance the shopping experience.
- **Admin Dashboard:** Built a comprehensive admin portal featuring inventory management, supplier tracking, real-time monthly/yearly revenue statistics with Chart.js, and dynamic role management.
- **Frontend Development:** Crafted a responsive, SSR-optimized, and accessible user interface using Next.js and Tailwind CSS. Utilized Shadcn UI for consistent, reusable components and dynamic light/dark themes.
- **File Management:** Integrated Cloudinary for seamless image upload, storage, and optimization for product listings.
- **Code Quality:** Applied modern practices including automated generation of TypeScript interfaces from backend OpenAPI specs, and enforced code style with Prettier, ESLint, Checkstyle, and Spotless.
