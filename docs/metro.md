### II. **HCMC Metro Smart Management System**

_A comprehensive digital infrastructure for managing metropolitan railway operations, featuring real-time monitoring and AI-powered security._

- **Tech Stack:**
    - **Frontend:** React 19, TypeScript, Vite, Ant Design (UI), Framer Motion (Animations).
    - **Backend:** Node.js, Express.js, PostgreSQL.
    - **AI/Security:** TensorFlow.js (Face Recognition), Face-api.js.
    - **Geospatial:** Leaflet & React-Leaflet (Interactive Metro Maps).
    - **Integration:** PayOS (Payment Gateway), Swagger (API Documentation), Node-cron.
- **Key Responsibilities & Features:**
    - **AI-Powered Authentication:** Developed a face recognition system using TensorFlow.js that aggregates facial descriptors from multiple angles (front, left, right) to ensure high-accuracy biometric login and ticket validation.
    - **Dynamic Metro Mapping:** Integrated Leaflet to visualize metro lines and stations, allowing administrators to manage geographic data and monitor system status in real-time.
    - **Financial Ecosystem:** Implemented an automated e-ticketing system with PayOS integration for seamless transactions and node-cron for automated ticket expiration and status updates.
    - **Admin Command Center:** Built a sophisticated dashboard using Ant Design and Recharts to manage customer data, line schedules, promotional gift codes, and comprehensive system statistics.
    - **Localization:** Implemented multi-language support (i18next) to ensure the platform is accessible to both local and international users.
